# Macaulay2 Certificate

This folder contains one Macaulay2 script:

```bash
M2 --script macaulay2/verify_stabilizer_lie_dimension.m2
```

The script is independent of the Jeffrey-Kirwan pairing computation.  It starts
from the displayed relation `R5` and checks a separate exact statement over
`Q`.

Let `A` be the free graded super-commutative algebra generated by

```math
f_2,a_2,f_3,a_3,f_4,a_4,f_5,a_5
```

and by the odd variables

```math
b_r^j,\qquad 2\le r\le 5,\quad 1\le j\le 4.
```

Let `R5` be the displayed degree-`22` relation.  The script builds every
degree-preserving derivation of `A`, applies it to `R5`, and computes the rank
of the resulting map

```math
\rho_R:\mathrm{Der}^{\mathrm{gr}}(A)\longrightarrow A^{22}/\mathbb Q R_5,
\qquad
D\longmapsto [D(R_5)].
```

The quotient is constructed directly: the script chooses one monomial that
appears in `R5`, uses the equation `R5 = 0` to eliminate that monomial, and
records the remaining degree-`22` coordinates.

Successful output is:

```text
expanded R5 support: 88
full degree-22 monomial count: 3868
Der^gr(A) columns: 468
quotient row count: 3867
rank of rho_R: 456
kernel dimension of rho_R: 12
Macaulay2 certificate passed: stabilizer Lie algebra dimension is 12 over QQ.
```

Thus the script verifies

```math
\mathrm{dim}_{\mathbb Q}\ker(\rho_R)=12.
```
